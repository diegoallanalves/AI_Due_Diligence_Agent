# AI Due Diligence & Value Creation Agent

A Streamlit prototype for financial-services investment diligence and post-investment AI value creation.

## How to use
1. Select a sample company or choose Custom.
2. Adjust assumptions in the sidebar.
3. Click **Run Due Diligence**.
4. Review investment score, risk profile, AI opportunities and value scenarios.
5. Challenge assumptions before drawing conclusions.

## Features
- Growth, financial, technology and risk scoring
- Investment attractiveness score
- Risk heatmap
- Investment-vs-risk chart
- AI value-creation opportunity discovery
- Conservative / Base / Aggressive scenarios
- Diligence roadmap
- Optional LLM executive summary

## Run
```powershell
pip install -r requirements.txt
streamlit run app.py
```

## Interview line
> I built this as a due-diligence and value-creation prototype rather than a generic chatbot. It combines business, financial, technology and risk signals to create an initial investment view, then identifies where AI could create measurable value and what should be validated next.

All companies and figures are synthetic demonstration data.
